 A TOML file is a configuration file format with the extension .toml that is designed to be minimal, easy to read for humans, and map unambiguously to data structures (like a hash table or dictionary) in programming languages. TOML stands for Tom's Obvious, Minimal Language. 

Key Features and Syntax
Key-Value Pairs: The basic building block is key = value.
Comments: Lines can be annotated with comments using the hash symbol (#).
Data Types: It supports various data types, including strings, integers, floats, booleans, datetimes, arrays (lists), and tables (sections).
Tables: Sections are defined using square brackets (e.g., [section_name]) to organize related key-value pairs, which become nested dictionaries in programming languages.
Case Sensitivity: TOML is case-sensitive.
Whitespace: Unlike formats like YAML, TOML's structure does not rely on indentation or whitespace for hierarchy, which reduces the chance of formatting errors. 
Common Uses
TOML is widely adopted in modern development tools, particularly within the Python and Rust ecosystems. 


A YAML(yet another markup language) file (.yaml or .yml) is a human-readable text file for data serialization, commonly used for configuration, data exchange, and storing structured data in applications, especially with tools like Kubernetes and Ansible, using simple syntax like key-value pairs and indentation to define structure instead of brackets or tags. It supports scalars, lists, and dictionaries, making it easy for humans and programs to understand and edit.

.d files (dependency files)

Why the weird hashes?
Rust supports:
multiple versions of same crate
different feature sets
different compilation units
So Cargo names artifacts as:

<crate-name>-<hash>
.rmeta files (Rust-specific)

libhello_world-xxxx.rmeta
This is NOT an object file

It contains:
type information
trait resolution data
symbol metadata

Used by:
rustc
rust-analyzer
incremental compilation
Think of it as:
“C++ module metadata + debug symbol index combined”

target/debug/build/
Created only if:
a dependency has build.rs
or native code is involved (C/C++)
